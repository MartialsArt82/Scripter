## Neu in Scripter 1.5

- **Eine Datei pro Roman.** `.scrpt` bündelt Manuskript, Kapitel, Storyboard, Projekteinstellungen und Anhänge. Am Desktop legt Scripter neue Projekte direkt in diesem Format an und aktualisiert die Datei beim Speichern.
- **Bestehende Projekte umwandeln.** Öffne die bisherige `roman.json` oder eine ältere Scripter-ZIP-Sicherung und wähle im Projektmenü **Als .scrpt speichern …**.
- **Zwischen Desktop und Android wechseln.** Android speichert den Arbeitsstand lokal in der App. Im Projektmenü kannst du eine `.scrpt`-Datei exportieren und auf dem anderen Gerät wieder öffnen.

Unter **Assets** findest du die Pakete für Windows, macOS, Linux und Android sowie die Prüfsummen.

**English below**

## What's new in Scripter 1.5

- **One file per novel.** The `.scrpt` format bundles the manuscript, chapters, storyboard, project settings and attachments. On desktop, Scripter creates new projects in this format and updates the file when you save.
- **Convert existing projects.** Open the original `roman.json` or an older Scripter ZIP backup and choose **Save as .scrpt …** in the project menu.
- **Move between desktop and Android.** Android saves your working project locally. Export a `.scrpt` file from the project menu and open it on the other device.

Download the Windows, macOS, Linux and Android packages and their checksums under **Assets**.
