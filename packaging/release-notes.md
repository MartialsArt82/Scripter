## Neu in Scripter 1.4

**Android-Aktualisierung:** Das linke Menü öffnet sich über die verfügbare Bildschirmhöhe und lässt sich auf kleinen Displays scrollen. Die APK kann als Update über die installierte Version 1.4 installiert werden.

- **Debian und Ubuntu (amd64)** erhalten ein `.deb`-Paket mit Anwendungsstarter. Installiere es mit `sudo apt install ./scripter_1.4_amd64.deb`.
- **Android ab Version 8.0** erhält eine signierte APK. Der Editor, die Kapitelwerkzeuge und das Storyboard sind für Touchscreens angepasst. Projekte werden lokal gespeichert und lassen sich mit Material als ZIP sichern und übertragen.
- **Fünf Oberflächensprachen** stehen unter **Einstellungen → Oberflächensprache** zur Wahl: Deutsch, Englisch, Französisch, Spanisch und Portugiesisch. Die Manuskript- und Wörterbuchsprache lässt sich unabhängig einstellen.
- **Android-Export** umfasst PDF über den Systemdruckdialog, EPUB, HTML und TXT. Diktat nutzt die Spracherkennung des Geräts. Die Transkription vorhandener Audio- und Videodateien, der paginierte Buchsatz und weitere Exportformate bleiben in der Desktop-App verfügbar.

Die Pakete für Windows, macOS, Fedora und Nobara sowie das Debian-Paket und die Android-APK stehen unter **Assets**. `STARTEN.txt` enthält die Installationshinweise.

**English below**

## What's new in Scripter 1.4

**Android update:** The left menu opens to the available screen height and scrolls on small displays. The APK can be installed as an update over version 1.4.

- **Debian and Ubuntu (amd64)** get a `.deb` package with an application launcher. Install it with `sudo apt install ./scripter_1.4_amd64.deb`.
- **Android 8.0 and later** get a signed APK with a touch-friendly editor, chapter tools and storyboard. Projects are stored locally and can be transferred as ZIP backups with their attachments.
- **Five interface languages** are available under **Settings → Interface language**: German, English, French, Spanish and Portuguese. Manuscript and dictionary languages can be selected independently.
- **Android exports** include PDF through the system print dialog, EPUB, HTML and TXT. Dictation uses the device's speech recognition. Transcription of existing audio and video, paginated book layout and additional export formats are available in the desktop app.

Download the packages for Windows, macOS, Fedora and Nobara, the Debian package or the signed Android APK under **Assets**. See `STARTEN.txt` for installation instructions.
